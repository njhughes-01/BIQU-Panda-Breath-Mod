# Native Panda MQTT Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Execute sequentially; one Strata builder slot.

**Goal:** reliable firmware-native device MQTT without Home Assistant in the device path.
**Architecture:** A separate authenticated device MQTT client implements the existing async send/recv socket seam. Normalize flat native state into the existing settings parser. Keep all legacy WS behavior as the default transport. A dedicated Mosquitto compose overlay supplies the broker.
**Tech Stack:** Python 3.12, existing paho-mqtt/websockets, pytest, Docker Compose, Mosquitto 2.
**Spec:** openspec/changes/native-panda-mqtt/design.md.

## Review focus
1. Native drying_running is drying-only: generic manual isrunning must never start/stop a dry timer accidentally.
2. Retained/other-device/invalid payloads must not establish fresh state or acknowledge a command.
3. Reconnect and cancellation while a start is awaiting settings must send no delayed start.
4. Dedicated broker outage or stale device status must not queue/replay commands or claim heater-off.
5. Native settings omit firmware/physical relay sensors: UI must say unconfirmed/unknown unless device evidence supports a claim.
