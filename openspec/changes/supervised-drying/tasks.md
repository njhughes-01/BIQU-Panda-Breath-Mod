# Supervised drying implementation plan

Goal: preserve an explicitly requested drying session across Panda reconnects while enforcing one host deadline and permanent mod cancellation.
Architecture: a persisted supervisor owns intent; native transport owns confirmed device operations; Panda.py connects existing controls and a periodic supervisor task.
Spec: design.md in this folder. Python/asyncio, existing MQTT; no dependencies.

Global constraints: native timer backup stays enabled. Never bypass device or mod locks. No live device commands, services, deployment, credentials, settings or firmware changes. Never arm on reconnect alone. Preserve existing settings and normal-start guard. Do not adopt old idle480min as an armed session. Outages count toward elapsed time.
Review focus: Stop/restart race; persistence failure must inhibit ON; stale/retained telemetry must inhibit ON; expiry with offline device must persist pending Stop; uncertain ON must not be replayed.
